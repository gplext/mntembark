AIRLINE PHOTOGRAPHS — candidate URLs to paste in the admin panel
================================================================
Admin → Airlines → edit an airline → "Photographs for the Flights page"
Paste into the URL box under the drop zone. Up to three per airline.

TWO THINGS TO KNOW BEFORE YOU USE THESE
---------------------------------------

1. I COULD NOT LOAD THEM. The sandbox I work in blocks image hosts, so I
   have not seen a single one of these pictures. What I did verify is that
   each file exists on Wikimedia Commons — every filename below came back
   from a Commons search — and the URLs are built with Commons' own naming
   scheme, so they should resolve. "Should" is not "did". Paste one and the
   thumbnail appears in the admin form straight away; if it does not, the
   URL is wrong and nothing is lost. Do not push these to the live site
   without looking at them first.

2. LICENSING. These are Wikimedia Commons photographs. Most are CC BY-SA,
   which allows commercial use but REQUIRES crediting the photographer, and
   the site has nowhere to put a credit at the moment. Open the Commons page
   listed under each one, check the licence box, and either add the credit
   somewhere or use a different picture. Public-domain and CC0 files need no
   credit. This is your call, not mine — I have flagged it rather than
   quietly putting someone else's licensed work on a commercial site.

   If you would rather not deal with credits at all, Unsplash and Pexels
   allow commercial use with no attribution. Search "airplane", "aircraft
   cabin", "airport terminal" there. They will be generic aircraft rather
   than the actual airline, which for a card behind the airline's name is
   usually fine.

THE STEP PHOTOGRAPHS
--------------------
Separate from the three above, each airline has two more slots: "Departure
from Pakistan" and "Onward to the destination". Those want a terminal or a
place, not an aircraft — Lahore or Karachi airport for the first, and the
arrival city for the second. An aircraft picture in all five slots makes the
itinerary read as a slideshow of the same plane. Leave them empty until you
have something specific; the page lays out correctly without them.
